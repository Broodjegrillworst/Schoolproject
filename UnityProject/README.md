# Afterglow: The Rootbound Bell

Een 2D actie-avontuur over Mara Vale, de laatste klokbewaarster van een oerwoudrijk dat door zijn eigen wortels is opgeslokt.

## Openen

Open deze map in Unity Hub met Unity 6000.6.5f1 en start `Assets/Afterglow/Scenes/AfterglowMenu.unity`.

## Besturing

- **A / D** — bewegen
- **Spatie** — springen
- **Linkermuisknop** — Oathroot, Mara's primaire wapen; vasthouden laadt een zwaarder schot
- **Rechtermuisknop** — Reliekstoot; bij een vol Wortelhart ontketent dezelfde knop de ultieme puls
- **E** — herinnering onderzoeken, verborgen doorgang gebruiken of gebarsten zegel openen
- **Esc** — pauzeren

**Shift** geeft een optionele ontwijkdash. Doelen markeren of rebounds uitvoeren is niet nodig voor gewone gevechten of eindbazen.

## Naar een ander apparaat kopiëren

De Unity-projectmap staat in `UnityProject/` van [Broodjegrillworst/Schoolproject](https://github.com/Broodjegrillworst/Schoolproject). Kloon de repository of download de ZIP op je Raspberry Pi om bij de projectbestanden te kunnen.

De achtergronden en personages hebben eigen SVG-bronnen in `Tools/AfterglowArtSource/source/overrides`; de bijbehorende PNG-bestanden staan in `Assets/Afterglow/Resources/Art`.
