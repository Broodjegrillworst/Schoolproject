# Afterglow: The Rootbound Bell

Unity 2D-project gemaakt met Unity 6000.6.5f1.

Open de map `UnityProject` in Unity Hub. De hoofdscene is `Assets/Afterglow/Scenes/AfterglowMenu.unity`.

De projectbestanden staan in `Assets`, `Packages` en `ProjectSettings`. Unity maakt cache- en buildmappen opnieuw aan; die zijn niet in GitHub opgeslagen.
