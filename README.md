# Afterglow: The Rootbound Bell

A 2D action adventure set in an overgrown jungle civilization. The Unity project lives in [UnityProject](UnityProject/).

## Open the project

Use Unity 6000.6.5f1 and open `UnityProject`. Start from `Assets/Afterglow/Scenes/AfterglowMenu.unity`.

## Controls

- **A / D** move; **Space** jumps
- **Left mouse** fires Oathroot; hold to charge
- **Right mouse** uses Relic Pulse (and releases the full Wortelhart charge)
- **E** interacts; **Esc** pauses
- **Shift** is an optional evasive dash

## Raspberry Pi access

Clone or download this repository on the Pi to browse and edit the source files and art. The project folder is `UnityProject/`. The included artwork sources are in `UnityProject/Tools/AfterglowArtSource/source/overrides/`.
